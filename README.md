# 全天球カメラ

スマホのカメラとジャイロで全方位を撮影し、360°写真につなぎ合わせる静的Webアプリ(PWA)。

- 撮影: 画面の輪に向けてスマホを動かすと、ジャイロで向きを検出して自動撮影
- 合成: 各写真の実際の向きを使ってエクイレクタングラー画像を生成
- 表示: WebGLの360°ビューア(通常 / リトルプラネット)
- 保存: Googleフォト等で360°写真として開けるJPEG(GPano XMP付き)

ビルド不要です。`index.html` ほかをそのままHTTPSで配信してください(カメラ・ジャイロはHTTPS必須)。
Vercelでは `vercel.json` の設定で、静的サイトとしてそのままデプロイできます。
